# 温知 · 学习内容管理界面

> 正式 v0.2.0 管理服务已实现，入口为服务的 `/admin/`，启动说明见 `../docs/RUNNING.md`。本目录继续保留最初的独立 HTML 设计原型，原型与正式服务数据不互通。

## 打开方式

直接使用现代浏览器打开 `index.html`。所有样式、SVG 插画和 JavaScript 均内嵌在 HTML 中，无需安装依赖、构建或联网。

也可在 `design` 目录运行 `python -m http.server 8765`，再访问 `http://localhost:8765`。

## 设计范围

- 内容总览 / 数据洞察：资料统计、入库趋势和格式分布。
- 学习资料库：音频、视频、文章、卡片轮播；列表与卡片视图、实时搜索、状态 / 类型 / 分类筛选、时间排序、分页、批量操作。
- 资料详情：预览、资料信息、操作记录；文章正文、音视频播放器、卡片翻页。
- 资料入库：本地文件拖放 / 选择、文章编辑、互联网链接登记。
- 审核与发布：草稿 → 待审核 → 已发布；仅已发布资料可进入推送计划。
- 专题合集：按分类自动归集资料，可创建新合集。
- 内容来源 / 客户端：RSS 与客户端接入信息登记，启停和模拟同步。
- 推送管理：创建定时计划、选择接收范围、暂停 / 恢复、模拟推送和记录查看。
- 辅助功能：通知、使用指南、CSV 导出、紧凑列表、显示名称设置、演示数据重置。

## 原型边界

这是独立的前端交互原型，**没有连接现有 Go API**，不会上传文件、抓取互联网正文、生成真实接入密钥或发送推送。

这是早期设计原型的边界，并非正式服务当前能力限制。v0.2.0 正式管理服务已实现多媒体上传、审核、持久存储和客户端收件箱投递，详见 `../docs/MANAGEMENT.md`。

演示资料、来源和计划均为示例。资料信息与设置使用浏览器 `localStorage` 保存（键名 `zhixu-design-v1`），不修改项目内的其他文件。若浏览器禁止存储，更改仅在当前页面有效。

上传的媒体通过浏览器临时对象 URL 预览；媒体文件本体不会保存到 `localStorage`，刷新后只保留资料信息，不再播放原文件。示例音视频不附真实媒体；示例文章与轮播正文已标明为排版演示。

如需重新开始，可进入「工作空间设置 → 重置演示数据」。

## 布局与操作

- 宽屏：完整侧栏、资料工作区、推送日程与活动侧栏。
- 中屏：收起导航文字，辅助信息调整到列表下方。
- 手机：抽屉导航、双列统计卡；资料表格可在自身区域横向滚动，也可切换卡片视图。
- `/`：聚焦搜索；全局搜索输入后按 Enter。
- `Esc`：关闭弹窗、菜单或资料详情。
- 对话框包含焦点约束，并支持减少动态效果的系统偏好。

色彩以深松绿、纸白与青柠色构成，界面字体使用系统字体，不依赖外部 CDN。
