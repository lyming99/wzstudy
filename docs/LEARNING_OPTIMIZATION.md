# 学习播放与共享渠道

更新日期：2026-11-01。对应笔记「学习模块优化」。本次范围是此仓库的 Go 服务端及 `/learn/` Web 学习页，不包含其他工程中的桌面、移动客户端或安装包发布。

## 学习数据上报

- 学习账号登录后拥有本人的学习上报能力。学习页读取 `/client/learning/capabilities`，明确显示「学习数据同步已开启」。查看、进度、有效播放时长、喜欢、收藏、私人笔记及复习沿用现有学习 API。
- 新查询客户端未指定权限时仍默认 `read + sync + feedback`。**不对已有显式只读 Key 自动扩权**；客户端 Key 仍不是用户身份，共用同一 Key 仍共用该客户端的学习状态。
- Web 播放器默认自动保存播放位置和有效播放时长；页面开关只控制这两项自动记录，不撤销账号能力，也不关闭用户明确执行的笔记、收藏及手动进度保存。
- 有效播放时长仅采样页面可见、媒体已加载且实际播放前进的时间段，不把暂停、缓冲、后台隐藏、直接拖动或整段媒体长度算作已学习时长。上报间隔约 15 秒，暂停及正常切换资料时尝试同步。
- 播放上报按播放器独立会话顺序提交，失败重试保留原事件 ID、时间范围和载荷，避免响应丢失造成重复计数。跨设备进度冲突时停止自动覆盖，需用户明确点击手动保存。
- 同步失败不替换已经打开的资料、媒体和正文；最后一次同步未确认时离开页面会提示。网络断开、浏览器强制关闭或最终同步失败仍可能丢失尚未确认的进度，本实现不在浏览器持久保存私人学习队列。

## 音视频播放

有可直接播放的受控媒体资产时提供：

1. **章节进度条**：鼠标/触屏拖动预览目标时间与所在章节；释放后定位；键盘可调整进度。原生媒体控制仍保留。章节大纲可直接跳转，普通内容大纲按需展开。
2. **自动下一集**：按当前授权查询的结果顺序播放，队列结束时继续读取后续页面，跳过不可直接播放的文章、外链与轮播。不更换资料筛选范围。
3. **单集循环**：本集播放结束后回到开始，不切换资料。
4. **指定队列范围循环**：选择本次已加载队列中的起始、结束集，范围内自动下一集，末集回到起始集。不会把未加载页面假装加入指定范围。
5. **仅播放本集**：结束后停止。
6. **字幕与歌词**：音频、视频均支持现有内联 SRT / WebVTT 字幕。字幕随播放高亮，可切换歌词列表、点击句子定位，支持原文轨及翻译轨选择；时间重叠用于双语对照，不要求两轨逐句一一对应。
7. **语言单句循环**：当前/选定字幕句循环，并可跳转上一句、下一句；优先级高于整集及队列循环。拖动进度或切换原文字幕时退出原单句循环。

没有字幕时隐藏歌词、翻译、单句操作，不虚构字幕。没有已上传媒体而只有外部链接时保留原始链接入口，不能在本站提供进度拖拽、循环或有效播放统计。

**翻译显示不等于自动翻译服务**：本次消费资料中实际提供的多语言字幕轨；不调用翻译模型、不产生外部翻译费用。

### 音频章节和字幕

原有 `chapters`、`subtitles` 字段现在同时接受 `kind=audio|video`，其余类型仍拒绝这些字段。原有最多 300 章、8 轨、字幕格式/大小、章节顺序和已知时长边界约束不变。管理工作台的资料编辑器可维护音视频章节/字幕 JSON。

```json
{
  "kind": "audio",
  "duration_ms": 8000,
  "chapters": [{"id": "intro", "title": "开场", "start_ms": 0}],
  "subtitles": [
    {"id": "en", "language": "en", "format": "srt", "content": "1\n00:00:00,000 --> 00:00:02,000\nHello"},
    {"id": "zh", "language": "zh-CN", "format": "vtt", "content": "WEBVTT\n\n00:00.000 --> 00:02.000\n你好"}
  ]
}
```

## 一账号一渠道，内容共享与学习状态分离

每个已有账号拥有一个稳定渠道 ID，首次读取默认 `private`、`revision=0`，不自动公开资料；无需接管历史无主数据或另建租户系统。账号原有数据源仍按工作区隔离。

在学习页顶部：

- **我的渠道**：维护渠道名称、说明、访问权限、共享来源及邀请邮箱。
- **共享渠道**：发现已登录用户可见或邀请当前账号的渠道，浏览其已发布资料。

### 访问权限

| 模式 | 谁可以访问 |
|---|---|
| `private` | 仅本人；默认值 |
| `public` | 本服务中已登录且启用的学习账号；**不是匿名互联网公开** |
| `invited` | 本人及邀请指定的学习账号 |

访客必须使用**自己的数据源服务学习账号**登录，不需要也不得共享提供者密码、录入 Key 或查询客户端 Key。未存在的邀请邮箱可以保存为待使用邀请；只有该邮箱对应的实际账号登录后才可访问。接口不通过邀请保存成功/失败、解析到的用户 ID 来披露账号目录。

来源选择是显式允许清单：不选表示不共享任何内容；后来新增来源不自动共享。渠道仅暴露选定且启用来源中的已发布资料，不暴露草稿、删除资料、来源密钥、采集配置、邀请名单或其他用户记录。原始资料库、管理接口、增量游标不会因为渠道共享而跨工作区混合。

渠道拥有者可以随时改为私有、修改邀请名单或移除来源。后续资料、媒体和新的学习事件请求重新核验当前权限；停用拥有者账号、停用来源、下架或删除资料同样阻止后续访问。**不能远程收回已经发送到访客设备的字节或清除浏览器已经缓冲的媒体**。

### 学习记录归谁

A 提供资料、B 和 C 学习时：

- 内容保持在 A 的工作区，不复制给 B/C，不改变资料所有者。
- B 的进度、时长、喜欢、笔记、草稿和复习进入 B 的个人记录命名空间。
- C 的对应记录进入 C 的个人记录命名空间。
- A 不会因提供内容而获得 B/C 的私人笔记、进度或学习记录。
- 分享查询客户端 Key 不满足此隔离需求；渠道接口只接受用户会话。

共享访问撤销后，访客原有私人学习历史保留，不删除或归给发布者；新学习事件必须再次获得内容访问权限。

## API

基础路径 `/api/v1`，以下接口均要求 `UserSession`，Cookie 写请求继续要求本站 Origin 和身份一致性保护：

```text
GET /workspace/channel
PUT /workspace/channel
GET /channels
GET /channels/{channel_id}/items?limit=12&offset=0&q=&kind=
GET /channels/{channel_id}/items/{item_id}
GET /channels/{channel_id}/items/{item_id}/media/{asset_id}
```

保存使用 `revision` 乐观锁；不可通过请求指定 `owner_id/user_id/client_id` 切换数据所有者。渠道来源 ID 必须属于当前用户。

```json
{
  "revision": 0,
  "name": "我的语言学习资料",
  "description": "公开的音频跟读材料",
  "visibility": "invited",
  "source_ids": ["<本人来源 UUID>"],
  "invited_emails": ["learner@example.test"]
}
```

列表始终只读取最多 `limit+1` 条匹配资料，以 `has_more` 驱动后续分页，不为返回首页而加载整个渠道。`total_is_exact=true` 时 `total` 是已知精确总数；还有后续页或空的越界页时不执行额外全量计数，返回 `total=-1`、`total_is_exact=false`。

共享资料返回的媒体 URL 绑定**渠道 + 资料 + 资产**；资产必须在该资料已发布版本中被明确引用，不接受仅存在于资产登记表或草稿中的附件。媒体支持 Range，缓存为 `private, no-store`。

访客继续通过原 `/client/learning/*`、`/client/feedback` 保存自己的学习数据；服务端只在已验证用户的学习请求中开放受渠道控制的内容读取，不扩大记录或内容写权限。

## 存储、升级与验证

渠道使用现有工作区记录存储及事务。PostgreSQL 需先应用新增迁移 `000014_learning_channels.sql`，扩展记录类型白名单并强制每工作区唯一渠道；就绪检查会检测新索引，未迁移时不误报可用。迁移不改写既有资料、所有者或权限，不自动创建公开渠道，也不自动扩权存量 Key。文件存储无需 SQL 迁移。

```text
node scripts/test-learning-player.cjs
python scripts/verify_learning_optimization.py
python scripts/verify_learning_postgres.py
go test ./...
go vet ./...
```

浏览器验证脚本需要已安装的 Go、Node、Python Playwright/Chromium 和 FFmpeg；FFmpeg 只用于本地生成短 WebM 测试素材，不下载外部视频。脚本独立构建程序，创建临时文件存储、随机测试端口和临时账号，上传真实 WAV 测试音频；不读取 `.env`、不连接现有业务库、不替换运行程序。截图和检查清单写入 `.artifacts/learning-optimization/`。PostgreSQL 实测需显式提供专用测试数据库，不能以文件存储测试冒充数据库实测。

前端资源内嵌于 Go 程序。仅完成源码修改不会使现有服务自动更新；使用现有部署流程重新构建和重启后才生效。桌面、移动客户端仍需在各自工程另行接入播放器与渠道协议。

兼容性修复：手动新建未分类资料时不再生成空标签，避免空标签触发校验而无法保存；编辑已有资料仍保留原有标签。旧工作区浏览器脚本同步使用实际保存响应、明确的退出按钮和现有 Key 权限说明进行回归。
