# 数据录入 / 数据查询改造：实现、验证与本地部署

## 已实现范围

### 后端

- 独立查询 Client 模型、持久化记录、创建/编辑/停用/轮换接口与只读鉴权；查询不再回退尝试 Source。
- Source 仅允许 ingest/upload，Client 仅允许 read/sync，同一应用需要两类身份。Key 只存哈希，明文仅创建/轮换/迁移生成时显示一次。
- 旧查询/混合 Source 的只读预检与显式、原子迁移；混合 Key 必须选择保留归属，另一侧生成新 Key，不复制到两个角色。
- 待迁移来源禁止普通编辑/轮换，防止丢弃原查询归属；保留停用、nil/[] 和已退役 inbox 的安全语义。
- HTTP、Skill、MCP 共用标准化、来源绑定、幂等更新、附件登记与成功回执。回执与资料同事务保存，不记录标题、正文或 Key，不伪造失败或历史批次。
- 公开快照、筛选/分页、媒体读取及客户端主动增量拉取继续保留；待审核修改不泄漏，下架产生删除墓碑。
- 移除专题模型/管理接口及独立业务，保留历史通用记录；推送、收件箱、SSE 不恢复，不新增学习记录或推荐算法。
- PostgreSQL 新增不可变迁移 `000003_input_query_identities.sql`；文件存储保持版本 1 并使用新记录种类。

### 前端

侧栏仅两个业务入口：

- 数据录入：资料管理、录入端管理、接入指引、入库记录。
- 数据查询：公开资料查询预览、独立查询客户端。

保留手动维护、RSS、上传、审核、媒体预览和设置作为辅助能力；旧 hash 兼容回落，不进入空白页面。来源和客户端的表单、Key 操作及接口指引不混用。

查询预览使用公开接口与管理员会话，不伪称已经验证某个客户端的实际 Key。Key 不进入 URL、日志或浏览器持久存储。

修复了编辑对象缺失时退化新建的边界；模态表单提交期间禁止关闭/切页，失去会话后迟到的创建/轮换/迁移响应不重新展示 Key。公开查询、入库记录和详情均处理迟到响应。

### MCP

新增 `mcp/wzstudy_ingest/server.py`，是实际 stdio 适配器，不是说明占位：

- 支持声明范围内的现代按请求元数据与旧版初始化调用。
- 默认只提供来源状态检查与资料入库；显式 --allow-root 后才提供受限目录文件上传。
- 不提供客户端查询、审核、身份管理、任意 HTTP、任意文件读取或外链下载工具。
- 凭据只从明确启动配置加载，工具参数不能改来源或端点；不自动重试写入，保留 commit_uncertain。
- 未替用户创建 MCP 来源、填写真实凭据、安装到 AI 应用或修改 MCP 信任设置。启用说明见 `mcp/wzstudy_ingest/README.md`。

使用既有启动器和工作区，未修改管理员凭据或重新初始化账号：

- 地址：`http://127.0.0.1:8091/admin/`。
- 运行方式：源码重建到 `bin/wzstudy-dev.exe`，沿用 `.local` profile 和 `.local/data`，未使用旧 `dist` 的 SkipBuild。
- 启动日志确认既有管理员 `created=false`；未读取真实密码代用户登录。
- 部署前原工作区有 5 条资料、5 个媒体资产、3 个来源，内容游标为 15；无待拆分查询/混合身份，因此未执行真实身份迁移或生成客户端 Key。
- 备份目录：`.local/backups/two-chains-20261025-181658/`。工作区快照及 5 个附件均做 SHA-256 校验，附件合计 182411973 字节，保留文件 ACL；未复制明文凭据文件。
- 部署后资料、来源/客户端凭据摘要、游标、变更流、管理员与历史通用记录保持不变；启动凭据文件的字节摘要也未改变。
- 就绪检查通过。实际服务的 HTML、JS、CSS 和 OpenAPI 字节摘要与当前源码一致，证明运行产物已更新，不只是改了文件。
- 新管理端路径拒绝匿名请求。管理路由先做认证，匿名访问旧管理路径可能先返回 401；已授权的旧业务路由 404 由隔离套件验证。公开 SSE/旧收件箱路径的实际服务检查返回 404。
- 原有资料的审核/公开状态未自动修改，待审核媒体不会因部署而被自动发布。

服务在当前本地进程中运行，未安装 Windows 常驻服务或开机任务。浏览器旧会话需刷新并重新登录，旧 `#push` 地址会回到数据录入。`dist` 既有发行包未覆盖，后续不要使用旧包的 SkipBuild 假定已经包含本次改造。
