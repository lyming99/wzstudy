# 学习路线图与思维导图管理

## 入口与边界

在管理端左侧选择 **学习路线图**（`/admin/#roadmaps`）。这是独立于“数据管理 / 合集管理”的管理员编排模块，不是客户端私人学习进度。

- 路线图、节点说明、节点顺序、分支折叠状态和资料引用保存在服务端。
- 仅管理员会话或管理 API Key 可以读写；录入端、只读 Key、查询客户端 Key 均不能访问。
- 当前版本不提供客户端公开查询、发布、学习进度同步或路线图自动推荐；不会改变既有资料/合集公开游标。
- 删除路线图、删除节点或移除关联，只改变路线图，不删除资料库内容。
- 无第三方 CDN、外部脚本或新增前端运行依赖。

## 使用流程

1. 点击 **新建路线图**。编辑器提供中心主题及“建立基础、专项练习、项目实践”三个初始分支；在点击保存前不会写入服务端。
2. 填写路线图名称和简介。名称与中心主题同步。
3. 点击画布中的节点，在右侧（窄屏为下方）编辑节点名称、学习说明和关联资料。
4. 用工具栏添加子节点、添加同级节点、删除分支；中心主题不能删除或移动。
5. 调整结构：
   - 桌面端拖动一个节点到另一个节点，将整个分支移动到目标下方。
   - 属性面板“上级节点”提供同样操作，适用于键盘和手机。
   - “上移 / 下移”调整同级顺序。不能移入自身、自己的下级，或超过层级上限。
6. 搜索资料库并添加关联。可关联现有已发布、待审核或草稿资料；一个节点最多关联 20 份不同资料。查看按钮打开现有资料详情，不复制资料正文。
7. 点击 **保存路线图**，或使用 `Ctrl+S / ⌘S`。列表支持按名称/简介搜索和分页，重新打开可继续编辑。

## 画布操作

- 拖动画布空白区域平移；手机可直接滚动查看。
- `+ / −` 调整缩放；**适应画布**重新定位完整可见分支。缩放/滚动位置是本次编辑视图，不持久化。
- 节点旁的 `− / +数量` 或工具栏折叠按钮控制分支；折叠状态随保存持久化。
- **撤销 / 重做**支持本次未保存编辑，最多保留 30 个历史快照；连续输入会合并。成功保存后重置历史。
- 聚焦画布节点时：`Insert` 添加子节点，`Enter` 添加同级（中心主题添加子节点），`Delete / Backspace` 删除分支；方向键切换节点。`Tab` 继续正常焦点导航。
- 在非输入框中可用 `Ctrl/⌘+Z` 撤销、`Ctrl/⌘+Shift+Z` 或 `Ctrl/⌘+Y` 重做。输入框保留浏览器原生文本撤销。

## 保存、冲突与失效关联

- 编辑不会自动保存，也不会在浏览器本地持久化草稿。离开模块、退出或刷新前会提示未保存修改；关闭/刷新提示受浏览器自身行为限制。
- 保存期间冻结编辑，阻止切换模块，避免覆盖正在提交的数据。网络超时后应先核对服务端结果，尤其是首次创建，不应盲目重复提交。
- 保存和删除都校验 `revision`。其他窗口已修改时返回 **409**；编辑器保留本地草稿并展示冲突，点击“载入最新版本”需确认放弃本地修改，不会自动覆盖或合并。
- 若资料后来被删除，原节点的引用保留并标记为不可用，仍可编辑路线图、查看结构或移除旧引用；不允许把已删除资料新关联到其他节点。

## 数据限制与存储

| 字段 / 结构 | 限制 |
|---|---|
| 名称 / 节点名称 | 必填，最多 200 个 Unicode 字符 |
| 简介 | 最多 2000 个 Unicode 字符 |
| 节点学习说明 | 最多 4000 个 Unicode 字符 |
| 节点总数 | 1–300 |
| 层级 | 最多 12 层，中心主题为第 1 层 |
| 每节点资料引用 | 最多 20 个不重复资料 UUID |
| 列表 | `limit=1..50`，`offset=0..10000`；界面每页 12 张 |

输入必须是 UTF-8，不接受 NUL、未知 JSON 字段或超过 4 MiB 的请求。节点 ID 必须是唯一非零 UUID，只有一个根节点，所有父引用必须存在、无环；根节点标题必须等于路线图名称。节点数组中的相对顺序决定同级顺序。

使用独立 `learning_roadmap` 通用记录，不改写历史 `plan`、合集、资料或学习记录。内存、文件和 PostgreSQL 复用现有 Store：文件模式随工作区保存和恢复；内存模式重启丢失。已有完整通用工作区表结构的 PostgreSQL 不需要本模块专用迁移，项目原有迁移仍须正常执行。

## 管理 API

基础路径 `/api/v1`，认证、Origin/CSRF 规则及错误封装与其他管理接口相同。

```text
GET  /admin/roadmaps?q=<名称或简介关键词>&limit=20&offset=0
POST /admin/roadmaps
GET  /admin/roadmaps/{id}
PUT  /admin/roadmaps/{id}
POST /admin/roadmaps/{id}/delete
```

创建请求（新建 `revision=0`；更新提交当前 revision）：

```json
{
  "revision": 0,
  "title": "Go 学习路线",
  "summary": "从基础到实践",
  "nodes": [
    {
      "id": "eb2c7e41-1bc4-4b6b-8ad4-9cce66c99cc0",
      "parent_id": "",
      "title": "Go 学习路线",
      "note": "",
      "item_ids": [],
      "collapsed": false
    },
    {
      "id": "f4702a1b-7a40-4320-a4b8-9ba5a59bf37c",
      "parent_id": "eb2c7e41-1bc4-4b6b-8ad4-9cce66c99cc0",
      "title": "基础语法",
      "note": "理解变量、函数和结构体",
      "item_ids": [],
      "collapsed": false
    }
  ]
}
```

创建返回 201，读取和更新返回 200，`data` 为完整对象（含 id/revision/created_at/updated_at）。列表返回 `items/total/limit/offset`，每条只有摘要、node_count 和去重后的 resource_count，不附带节点说明。

删除正文 `{"revision": N}`，成功返回 `{"data":{"deleted":true}}`；再次读取为 404。非法结构 400，鉴权失败 401，CSRF 拒绝 403，陈旧版本 409。完整机器契约见 `openapi.json`。

## 生效方式

前端文件嵌入 Go 可执行文件，修改源码后需重新构建并重启部署中的服务；刷新旧可执行文件提供的页面不会加载新模块。本次开发和隔离测试本身不等于已经部署到现有运行服务。
