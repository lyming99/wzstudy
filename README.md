# WzStudy · 温知学习系统

## 简介

温知学习系统，主要用于[wenzflow](https://wenzflow.com)学习模块，目标是支持RSS订阅，以及AI自动采集互联网各种数据，形成视频、音频、文章、轮播图等数据，推送到客户端的学习系统，进行系统化学习与复习，巩固行业知识，成为领域专家。

学习的目的在于解决类似下面几个问题：

- 面试问题：通过大量学习，解决行业面试问题
- 考证问题：通过大量学习，解决考证问题
- 行业资讯：用于培养灵感，关注行业热点，结合专业知识，输出内容
- 英语学习：通过音频、字幕，结合记忆系统，实现英语学习

没有对比就没有好坏，学习就是将内部不好的去除，将好的留下，因此每天学习2个小时，可以促进持续进步。

## 功能列表

- [x] 数据录入：RSS录入、AI采集
- [x] 数据查询：客户端接入、扫码接入
- [x] 学习反馈：系统对学习动作进行统计，给出推荐学习内容
- [ ] 学习路线图：通过思维导图管理学习路线，系统化学习
- [ ] 学习分享：分享学习数据，共同学习
- [ ] 定时任务：系统定时采集最新内容，支持指定内容采集
- [ ] 智能采集：通过skill、mcp接入，直接远程让ai采集内容
- [ ] 数据统计：学习、复习数据统计功能
- [ ] 记忆系统：安排最合理的时间点复习关键内容，实现抗遗忘

## 快速开始

下面以 Windows 本地运行为例，使用 PostgreSQL 存储。

1. 安装 Go 1.25+、Docker Desktop 和 Docker Compose v2，并启动 Docker Desktop。

2. 在项目根目录打开 PowerShell，首次配置时复制 `.env.example`：

   ```powershell
   if (-not (Test-Path .env)) { Copy-Item .env.example .env }
   ```

   打开 `.env`，配置首次登录的管理员邮箱和密码，并可按需修改附件存储路径：

   ```dotenv
   DATA_DIR=.local/postgres-local/data
   SYSTEM_ADMIN_EMAIL=your-email@example.com
   SYSTEM_ADMIN_PASSWORD=your-own-strong-password
   ```

   请将示例邮箱和密码替换为自己的值，两项必须同时配置；密码需为 8–128 个 UTF-8 字节。已有 `.env` 不会被上述命令覆盖，不要分享或提交包含密码的配置文件。`DATA_DIR` 只保存附件，PostgreSQL 数据保存在 Docker 数据卷中。

3. 在项目根目录启动服务：

   ```powershell
   .\start-local.ps1
   ```

   也可以双击 `start-local.cmd`。脚本读取 `.env` 中可选的 `DATABASE_URL` 和 `POSTGRES_PASSWORD`，启动专属本机 Docker PostgreSQL、执行数据库迁移，再启动服务。如果未配置数据库密码，首次启动会生成随机密码，并将连接、密码、API 密钥和本机卷身份写入 `.env`；以后复用，不会输出密码或生成 `connection.json`。启动器会限制 `.env` 的 Windows 文件访问权限。首次启动可能需要联网下载依赖和镜像；连接格式与限制见[运行文档](docs/RUNNING.md)。

4. 打开终端显示的工作台地址，默认是 `http://127.0.0.1:8091/workspace/`。无需选择身份，直接使用邮箱和密码登录；管理员和普通用户都能录入、管理和学习自己的资料，管理员额外拥有用户管理功能。首次使用空数据库时，可用 `.env` 中配置的管理员邮箱和密码登录；如果两项都留空，脚本使用默认邮箱 `admin@wzstudy.local`，生成随机密码并写入 `.env`。每个账号的资料和学习数据仍相互隔离。

   **已有管理员不会被重置**：如果此前已用默认账号完成初始化，修改 `.env` 不会更改其账号和密码；若配置的管理员邮箱与已有账号不一致，服务会拒绝启动并提示检查配置。不要删除数据库或数据卷；请恢复原管理员邮箱并使用原凭据。

保持启动窗口打开，按 `Ctrl+C` 停止服务；以后重新运行 `.\start-local.ps1` 即可。备份时请同时安全备份数据库、附件目录和含明文密钥的 `.env`。旧版连接文件可自动核验并迁入 `.env`，原文件不会自动删除；旧文件模式的数据不会自动迁移或删除。更多说明见 [运行文档](docs/RUNNING.md)。

## 相关问题

### 为啥不直接到平台直接观看内容？

学习系统只关注自己关注的内容，避免学习过程被中断，只专注系统的建立，而非零散知识，今天学、明天忘记。

### 这个系统适合哪些人？

面试时，需要快速巩固专业知识时；

学习语言时，可以通过系统采集专业的语言资料，创建双语言对照，通过记忆系统，进行最科学的复习安排；

考证之类，可以通过系统进行主题针对性学习训练，巩固专业知识；

自媒体运营，可以通过ai采集行业热点，通过自己最擅长的专业，达到蹭热点的效果；

总之，学习系统，面向所有爱学习的人开放，并且免费开源。
